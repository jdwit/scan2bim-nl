# Survey day checklist

One pass through an empty building. Most of this cannot be repeated once demolition starts,
so treat it as a single take.

## Bring

- [ ] Laser distance meter (and a spare battery)
- [ ] 5 m tape measure
- [ ] Cross line laser or spirit level, for floor level differences
- [ ] Masking tape and printed A4 markers with a high contrast pattern
- [ ] Marker pen, printed control sheet, clipboard
- [ ] Phone with plenty of free storage, plus a power bank
- [ ] Camera or phone for room photos

## Before scanning: the control network

Do this first. It is the reference everything else is checked against.

- [ ] Tape a named marker (A, B, C, ...) at each end of every planned control distance
- [ ] Per storey: four to six long shots, including at least two full diagonals
- [ ] Per room: width, length and **both** diagonals
- [ ] Per storey: floor-to-ceiling at three or more locations, plus floor-to-floor
- [ ] Exterior wall thickness in a window reveal, per facade and per building phase
- [ ] Interior wall thicknesses, at least one per wall type
- [ ] Window openings: width, height, sill height, glazing bar layout, per type
- [ ] Staircase: number of risers, rise, going, stairwell opening
- [ ] Basement clear height and access position
- [ ] Floor level differences between rooms
- [ ] Photograph every measurement point

## Scanning

- [ ] Open all doors, pull curtains aside, lights on
- [ ] Cover mirrors; expect noise around glass
- [ ] One scan per room, two to four minutes each
- [ ] Walk slowly at 1.2 to 1.5 m height, 1.5 to 3 m from surfaces
- [ ] Close a loop: end each scan where it started
- [ ] Two passes per room: one for walls, one aimed at floor and ceiling
- [ ] Start each new scan inside the previous room, so scans overlap in the doorway
- [ ] Stairwell separately and slowly
- [ ] Basement and attic separately
- [ ] Second capture app as a free backup

## Facades

- [ ] Photo series all round, 60 to 80 percent overlap
- [ ] Three heights: low, eye level, as high as you can reach
- [ ] Overcast light beats bright sun
- [ ] Put a known length in shot, such as a 2 m staff, as scale reference

## Before leaving

- [ ] Every control distance written down and photographed
- [ ] Every room scanned and named consistently
- [ ] Markers still readable in the last scan
- [ ] Attic and basement covered
- [ ] Copy raw scans off the phone the same evening, into `raw/scans/`
